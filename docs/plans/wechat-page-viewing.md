# 群聊页面直接浏览原消息

目标：修复主导航 /wechat 只能看到待生成摘要、无法直接阅读已入库消息的问题。默认显示原消息，支持选群和历史翻页；摘要保留为独立标签。保持登录保护和 no-store，不开启模型、不迁移数据库。

验收：真实已登录 HTTP 页面包含六群入口和实际消息节点；切换群、第二页和历史深页返回对应不同消息；匿名请求不能取得内容。模拟 SSR 测试覆盖默认原消息、摘要路径及分页。浏览器自动化目前不可用（CUA native pipe 启动失败、iab 不可用），不得把 HTTP 验证写成浏览器视觉验收。

## 2026-10-15 实施与验收

- 根因：主导航 /wechat 原先只请求摘要 API，默认显示待生成摘要；数据库 370,196 消息与 1,112 pending 摘要并不意味着该入口有原消息可读。
- /wechat 默认通过已登录的 adminGet 读取原消息，显示六群导航、计数、发送者、正文和时间。保留摘要为 ?view=summary，历史摘要 day 链接保持兼容。分页和群切换保留 account/group，历史原消息不依赖模型。
- 主导航名称更新为“微信群聊”。已有管理接入页保留，无新增 API/数据库表、无迁移、无开启模型。
- typecheck、生产构建、40 项网页测试和 diff check 通过。新增默认入口不依赖摘要、正文转义与撤回标记的 SSR 回归。
- 仅更新运行中 web 容器的编译产物，未重建 API/worker/setup。
- 使用真实现有密码正常登录运行站点，凭据与正文未输出：默认 HTML 100 个实际消息 li；六群页面逐一与真实 API 的消息 ID 和转义正文比对一致；第二页返回不同消息；最大群第 2042 页包含 14 条消息，最早年份 2025；匿名访问 302，no-store 保留。
