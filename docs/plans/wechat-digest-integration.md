计划增加 `0043_wechat_digests.sql`，只新增一张摘要表，不修改原消息表，不迁移/删除现有消息：

```sql
CREATE TABLE wechat_digests (
  account text NOT NULL,
  group_id text NOT NULL,
  day date NOT NULL,
  revision bigint NOT NULL DEFAULT 1,
  status text NOT NULL DEFAULT 'pending'
    CHECK (status IN ('pending', 'ready', 'error')),
  input_hash text,
  points jsonb NOT NULL DEFAULT '[]',
  message_count integer NOT NULL DEFAULT 0,
  error text,
  updated_at timestamptz NOT NULL DEFAULT now(),
  attempted_at timestamptz,
  PRIMARY KEY (account, group_id, day),
  FOREIGN KEY (account, group_id) REFERENCES wechat_groups (account, group_id)
);
CREATE INDEX wechat_digests_pending ON wechat_digests (status, attempted_at);
```

按群和北京时间日期总结；消息新增/修改/撤回使对应摘要变为 pending 并增加 revision。模型处理后只在 revision 未变化时发布，避免旧结果覆盖新消息。每个要点保存证据消息 ID。原消息继续保存在私有表，摘要不会转成公开 articles。

验证数据库拟新建独立空库 `wechat_integration_20261007_test`，只对该库执行仓库迁移和合成测试。真实业务数据库不在本次迁移授权范围内。
